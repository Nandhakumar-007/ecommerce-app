# ShopZone

# React E-Commerce Store

A modern and responsive E-Commerce web application built using React.js and Vite. The application provides a complete shopping experience, allowing users to browse products, manage their cart, place orders, and track order history. User sessions, cart data, and order information are persisted using Local Storage to ensure a seamless experience across browser refreshes.

## 📦 Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd ecommerce-project
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local server URL displayed by Vite in your browser.

## 🔄 Application Flow

1. Products are displayed on the home page.
2. User adds products to the shopping cart.
3. if user try to open the cart it force to login
4. Cart data is stored in Local Storage.
5. User proceeds to place an order.
6. Order details are saved in Local Storage.
7. Order success page confirms the purchase.
8. Previous orders can be viewed in the Order History page.

## 💾 Local Storage Usage

The application uses Local Storage to:

* Maintain user login sessions
* Persist cart items across page refreshes
* Store order information
* Display order history
